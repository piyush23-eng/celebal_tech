# Week 3 — Superstore Sales Analysis

## 🎯 Objective

Apply subqueries, CTEs, and window functions in SQL to derive customer sales insights from the Superstore dataset — the direct precursor to the 16-query advanced SQL analysis built in Week 8.

## 🛠️ Approach

SQL-based analysis of the Superstore dataset, layering progressively more advanced SQL techniques on top of the basic querying from Week 2:
- Subqueries for filtering and comparison logic
- CTEs to break multi-step logic into readable, named stages
- Window functions for per-customer / per-segment calculations that plain `GROUP BY` can't express

## 📈 Key Insights

- Top customer (**Sean Miller**) generated **$25,043.05** in total sales
- **12 customers** placed only one order and never returned
- Average customer spend: **$2,896.85**, with only **294 / 793 (~37%)** of customers spending above average

## 📁 Output

- SQL script(s) with all queries
- Brief summary of findings

## 🔧 Tech Used

SQL (SQLite / MySQL) — Subqueries, CTEs, Window Functions
